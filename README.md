# 🍔 Rockburger — Web App Interactiva

Página web responsive e interactiva para el restaurante de estética rockera **Rockburger**, desarrollada con tecnologías web nativas.

## 🚀 Características
- **Diseño Responsive:** Adaptado a pantallas de escritorio y dispositivos móviles mediante CSS3 y `@media queries`.
- **Filtro de Menú Dinámico:** Clasificación de platillos en tiempo real usando atributos `data-*` y JavaScript nativo.
- **Formulario de Reservas:** Validación en tiempo real para evitar fechas pasadas e ingresos de teléfonos inválidos.
- **Persistencia de Datos:** Uso de `localStorage` para conservar la reserva activa del cliente incluso tras recargar la página.

## 🛠️ Tecnologías Utilizadas
- **HTML5:** Estructura semántica.
- **CSS3:** Tema oscuro (`#000`), acentos neón (`#b9df11`), Flexbox y diseño en bloques.
- **JavaScript Vanilla:** Manipulación del DOM, gestión de eventos y Web Storage API (`localStorage`).
